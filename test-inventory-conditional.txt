# Tests that exist on some platforms and not others, so no single
# `test-inventory.txt` can pin them: the file is generated on one machine and
# checked on another (CI is `ubuntu-latest`, development here is macOS), and a
# `#[cfg(target_os = ...)]` test is a line on one side and absent on the other.
#
# Every line below is dropped from both sides before the diff. That is exactly
# the deletion the gate stops catching, so a line here needs the same
# justification a `-` line in a PR diff would get: say why the test cannot be
# written to compile everywhere. "It is slow" or "it is flaky" is not a reason
# to list it here.
#
# Blank lines and `#` lines are ignored. Everything else must match a full
# inventory line, byte for byte: `package<TAB>kind/target<TAB>test name`.

# layer does rather than what the docs claim, so there is nothing portable left
# once the platform layer is stubbed out.
