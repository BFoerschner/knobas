# Triage labels

The mattpocock skills name five triage roles. This repo uses the same strings.

| Role in the skills | Label here | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer has not evaluated it yet |
| `needs-info` | `needs-info` | Waiting on the reporter |
| `ready-for-agent` | `ready-for-agent` | Fully specified, an agent can take it |
| `ready-for-human` | `ready-for-human` | Needs a person |
| `wontfix` | `wontfix` | Will not be actioned |

`backlog` (CLAUDE.md) is this repo's own: filed, not dispatched until promoted.
