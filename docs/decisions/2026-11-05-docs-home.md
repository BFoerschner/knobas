# `#/docs` is a place: the Docs home, 2026-11-05

Björn ruled this on 2026-11-05, on the UX polish PR (#2479). It binds as Björn's ruling, not an agent's. The design is an agent's and is written down in the design system (*Layout*).

## The ruling

A bare `#/docs` no longer reopens the last page read, or the first page of the first space. It is a page of its own, so Docs has somewhere to go back to: Back to Docs and the Docs crumb lead to it from any doc page.

## What follows from it

- The hack that hid *Back to Docs* on the page read last is gone, because that page now has a home behind it.
- `pageToOpen` answers `null` for the home, and the home records no visit. The page read last is still read from `docs_tree` and is offered as *Continue reading*.
- `#/docs/search/<words>` keeps drawing the page read last under its hits: the ruling names `#/docs`, not the search.
- `Esc` on `#/page/...` goes to `#/docs`, as it did. No backend read, migration or IPC command changed.
- `mockups/ticket-first/requirements.md` keeps its §10 text with a note, as the record of what `#/docs` was.

## Cost of reversing

Making `pageToOpen` answer `tree.last_read` for the home again, and restoring the hidden hint, brings back the old address. Nothing is stored.
