# Every other integration test lives in its crate's one binary,
# `tests/it/main.rs`, as a module named after the file it came from.
# `scripts/test-layout.sh guard`, run by `just check`, fails on a top-level

# whose file no longer exists.
#
# One file per line: `<crate>/<file>` (the file without `.rs`), then its reason.
# The reason is required. Lines starting with `#` and blank lines are ignored.
