payments-api

cipassingmsrv1.82

The service that takes card and SEPA payments for the shop and tells the rest of the estate about them over webhooks. It owns the payments schema and nothing else. See docs/runbook.md for operations and the Gitea wiki for the history.

Getting started

shell
# needs Postgres 16 on :5432
just db-up
cargo run -- --config config/dev.toml
