Setup

Info

Takes about 30 minutes on a fresh laptop. Ask in #eng-help if a step fails.

  1. Install the toolchain:

    bash
    brew install rustup openjdk@21 postgresql@16 just
rustup-init -y

  2. Clone the repos into ~/code: payout-service, ledger-api, tidewater-schemas.

  3. Start the dependencies:

    bash
    cd ~/code/payout-service
just deps-up   # postgres + localstack

  4. Run the tests: just test.

Services and ports

just deps-up starts these in Docker, so Docker Desktop has to be running first. Each one answers its health check within a minute on a warm machine; the first pull of the localstack image takes longer.

ServicePortImageHealth check
postgres5432postgres:16.4-alpinepg_isready -h localhost -U payout
localstack4566localstack/localstack:3.8curl -s localhost:4566/_localstack/health
ledger-api8081built from ~/code/ledger-apicurl -s localhost:8081/actuator/health

When a step fails

Most failures on a fresh machine come from a port already in use, usually an older Postgres from Homebrew that is still running. Stop it, check nothing else holds the port, and recreate the containers:

bash
brew services stop postgresql@14 && lsof -nP -iTCP:5432 -sTCP:LISTEN; just deps-down && just deps-up --force-recreate
